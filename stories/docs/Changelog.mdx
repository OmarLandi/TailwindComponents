## [1.0.0] - 2026-02-20

### Added

#### Componentes

- **Button**: Botón versatile con múltiples variantes (default, destructive, secondary, accent, outline, ghost, link), tamaños (sm, default, lg, icon), estados (loading, disabled), y soporte para iconos.
- **Container**: Contenedor responsive con diferentes tamaños (xs, sm, md, lg, xl, 2xl, full), opciones de padding y soporte para fluido.
- **DropdownMenu**: Menú desplegable basado en Radix UI con soporte para items, checkboxes, radios, labels y separadores.
- **Select**: Selector basado en Radix UI con opciones de tamaño, labels, separadores, texto de ayuda y errores.
- **TextField**: Campo de texto con label, helper text, mensajes de error, iconos y variantes (default, filled, ghost, underlined).
- **ErrorBoundary**: Componente para capturar errores de React y mostrar un fallback.
- **ThemeToggle**: Botón para alternar entre modo claro y oscuro.
- **ThemeProvider**: Proveedor de tema global con soporte para light/dark mode y múltiples paletas de color.

#### Paletas de Colores

13 paletas de colores disponibles:

- neutral, stone, zinc, slate (escalas grises)
- violet, rose, orange (colores cálidos)
- emerald, blue, green (colores fríos)
- red, indigo (colores intensos)
- amber, cyan (colores especiales)

#### Sistema de Temas

- ThemeProvider con hook useTheme
- Soporte para light/dark mode
- Persistencia en localStorage
- 13 paletas de colores
- Variables CSS dinámicas

#### Documentación

- Storybook con autodocs
- Stories para todos los componentes
- Documentación de props
- Ejemplos interactivos

#### Testing

- Tests con Vitest
- Pruebas de accesibilidad con axe-core
- Tests para todos los componentes
