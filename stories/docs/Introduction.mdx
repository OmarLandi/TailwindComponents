# Librería de Componentes

Una librería de componentes React moderna y accesible construida con las mejores prácticas de desarrollo.

---

## Tecnologías

| Tecnología       | Propósito                         |
| ---------------- | --------------------------------- |
| **React 18**     | Biblioteca de UI                  |
| **TypeScript**   | Tipado estático estricto          |
| **Tailwind CSS** | Estilos con variables CSS         |
| **CVA**          | Variantes de componentes          |
| **Radix UI**     | Componentes primitivos accesibles |
| **Storybook**    | Documentación interactiva         |
| **Vitest**       | Testing unitario                  |
| **axe-core**     | Pruebas de accesibilidad          |
| **lucide-react** | Iconos                            |

---

## Requerimientos

### Dependencias necesarias

```bash
npm install react react-dom
```

### Instalación de la librería

```bash
npm install libreria-componentes
```

### Configuración Tailwind

Asegúrate de tener Tailwind configurado con las variables CSS del theme:

```javascript
// tailwind.config.js
export default {
  content: ['./node_modules/libreria-componentes/**/*.{js,ts,jsx,tsx}'],
  theme: {
    extend: {
      colors: {
        background: 'hsl(var(--background))',
        foreground: 'hsl(var(--foreground))',
        primary: {
          DEFAULT: 'hsl(var(--primary))',
          foreground: 'hsl(var(--primary-foreground))',
        },
        // ... más colores
      },
    },
  },
  plugins: [],
};
```

### Uso básico

```tsx
import { Button, ThemeProvider } from 'libreria-componentes';
import 'libreria-componentes/style.css';

function App() {
  return (
    <ThemeProvider colorMode="light" defaultPalette="neutral">
      <Button>Hola Mundo</Button>
    </ThemeProvider>
  );
}
```

## Accesibilidad

Todos los componentes cumplen con WCAG 2.1 nivel AA:

- Soporte completo de teclado
- Roles ARIA apropiados
- Contraste de colores verificado
- Screen reader compatible
